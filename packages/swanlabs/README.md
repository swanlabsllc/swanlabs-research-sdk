# swanlabs

Official public Python package for **Swan Labs, LLC** (<https://swanlabs.si>) — applied mathematics, formal verification, and software engineering R&D.

## Installation

```bash
pip install swanlabs
```

## Quickstart

```python
import swanlabs

print(swanlabs.__version__)
print(swanlabs.ORGANIZATION)
```
