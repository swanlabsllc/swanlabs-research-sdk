# swanlabs-sdk

Official public Python SDK for **Swan Labs, LLC** (<https://swanlabs.si>) public verification and telemetry endpoints.

## Installation

```bash
pip install swanlabs-sdk
```

## Quickstart

```python
from swanlabs_sdk import SwanLabsPublicClient

client = SwanLabsPublicClient()
print(client.version)
```
